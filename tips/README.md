# Tips & Tricks

Scripts which can help with interfacing with the Raspberrpyi Pico.

* [Threading](threading/README.md)
  Use both cores on the PicoPi.
* [Scan I2C bus](scan_i2c_bus.py)
  Scan all the possible I2C gpio-pins for the 2 busses on the Raspberrypi Pico.
* [Watchdog](watchdog.py) 
  Oneline to disable the watchdog after you enabled it.
