# BME680

[Robert-hh](https://github.com/robert-hh/BME680-Micropython) has a working micropython implementation for the BME680 sensor. 
Copy the `bme680.py` file to the `lib` folder on the Raspberry Pi Pico (or the folder in which your other scripts are) and run the following wexample:

```python
import time
from machine import Pin, I2C
import bme680

i2c = I2C(0, sda=Pin(0), scl=Pin(1))  # Correct I2C pins for RP2040
bme = bme680.BME680_I2C(i2c)

while True:
    print(bme.temperature, bme.humidity, bme.pressure, bme.gas)
    time.sleep(1)
```
