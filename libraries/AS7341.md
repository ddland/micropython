# AS7341

Optical light sensor which can identiy 10 different colors (including NIR and clear). 

[AHSPC](https://github.com/AHSPC/AS7341_micropython) created a micropython library. Copy this file, the [i2c_devide rewrite](https://github.com/AHSPC/adafruit_i2c_device_micropython) and the whole [Adafruit register](https://github.com/adafruit/Adafruit_CircuitPython_Register/tree/main) folder to the `lib` folder on the Raspberry Pi Pico.

Example code for getting the colors (spectral bands:)
```python
from time import sleep
from machine import I2C, Pin
from adafruit_as7341 import AS7341

i2c = I2C(0,sda=Pin(0), scl=Pin(1))
sensor = AS7341(i2c)

sensor.led = True

for _ in range(100):
    readings = sensor.get_readings()
    # print(readings)

    # Prints the color name and value for whatever the strongest wavelength is.
    # NOTE: this is not really a very accurate way to tell which color the sensor is seeing.
    maxK = ""
    maxV = 0
    for k, v in readings.items():
        if v > maxV:
            maxV = v
            maxK = k
    print(maxK, maxV)

    # sleep(0.05) # not necessary, as sensor.get_readings() takes a bit of time anyways


sensor.led = False
```

The `get_readings` method will get the value of the spectral bands (not scaled to physical values, only to fraction of the ADC), which can be converted to colors. The `clear` and `NIR` bands are hidden in the code. The function `all_channels` in the `Adafruit_as7341.py` file needs to also add the last two values in the F5-F8 bands to the `reads` list.
